  k 个坏弧并集测度 ≤ 1；若全覆盖 [0,1) 则测度恰 1 ⟹ 完美无重叠铺砌 ⟹
  各 Bᵢ 端点必须精确对齐 ⟹ 与互异速度下区间端点的有理结构矛盾 ⟹ 缝隙存在。
- **当前停点**：V5.5 中 Explorer-Entropy 与 Explorer-RealAlgebra 各产出过
  **编译通过的 sorry 骨架**（覆盖/测度框架已立）；死因指纹集中在 mathlib
  `Measure` 命名空间 API 与连续性转换的机械细节，非数学障碍。
- **修复策略**（参照 CRT 引理成功模板）：架构师手写 — 用区间覆盖的离散化
  （有理端点扫掠，`lrc_core` 精确判定器同款思路）+ 测度铺砌矛盾的有限归纳，
  避开 Measure API 深水区，omega/整除链收口。预估 1-2 会话闭环。
- **产物价值**：全球首个弱 LRC 界 (1/(2k)) 的 Lean 4 0-sorry 形式化。

### N3. f(k) ≥ 2k−4 下界 — 初等 Presburger 级 ★★★★

- **数学事实**：k 个两两互素合数至多 1 个偶数（偶数共享因子 2）⟹ 至少 k−1
  个奇数；但跨度 2k−5 的窗口只有 k−2 个奇数 ⟹ 矛盾。纯鸽巢。
- **停点**：数值侧 k≤10 已扫（f(4)=4 … f(10)=16 见证齐全）；Lean 侧未动工。
- **修复策略**：omega 直闭候选（与 CRT 引理同难度档）。配合 k=7..10 显式
  见证（窗口图团搜索已产出）构成"下界+锐性证据"双定理包。

### N4. m=3 j=1 投影情形证书 — 已证但铁律拦截 ★★★

- **数学事实**：λ₁((P₁+P₂+P₃)/3) ≥ |c₁₂c₂₃|，证明两行（测试向量 u₂ +
  (a−b)²+1−ab ≥ 0）。查新判 DUPLICATE_KNOWN（判官独立复现证明）。
- **定性**：数学上教科书级初等，按独创铁律**不得**作为独立成果点火；但可
  作为**弱界形式化的引理组件**复用（Rayleigh 商测试向量手法）。

### N5. 定量稳定性定理（ℝ³ 单位距离 5 边 ε 扰动）— 未成文原创候选 ★★★★

- **数学事实**：T1: dist ≤ √3 + 2ε（实测最优常数 → π/2 ≈ 1.57）；T2:
  dist ≥ √3−δ ⟹ ‖p₂+p₄−p₁−p₃‖² ≤ 5(δ+ε)（实测 ≈ 4.7）。均已数值验证。
- **停点**：命题已设计完毕、常数安全，从未点火（当年判官亲荐"有意义新
  结果"）。证明路线：极化恒等式 + Cauchy-Schwarz 链。
- **定性**：folklore 级未成文 — 本清单中**原创性最强的可证定理**。

### N6. 14 跑者主同余类 mod 191 筛法 — 证据强但证明开放 ★★★★★（深度）★（可证性）

- **数学事实**：v ≡ (1..13) mod 191 主类 300/300 采样通过（最险缝隙

  此即全球空白的技术根源。
- **定性（零幻觉声明）**：这是**证据支持的猜想片段，不是已证定理**。采样
  通过 ≠ 证明；打通需要"合数 k+1 广义筛法"的数学突破。诚实标注：非近失，
  是主攻方向。

## 板块二：被搁置的跨界神级灵感 (Cross-Domain Vault)

57 次突变、20 次 FEASIBLE 放行的完整轨迹图已存 `mutation_hub_state.json`。
逐流派审计：

### H1. 调和分析·波赫纳正定核流（Explorer-Harmonic）

- **降维直觉**：K̂(0) > Σ|K̂(vᵢ−vⱼ)| ⟹ 积分均值 > 0 ⟹ 孤独时刻。理论美感
  极高（Tao 2018 博客同源路线）。
- **真实根因**：**理论边界不够，非工具链受限** — 核方法给出的是 L² 平均意义
  下的存在性，而 LRC 需要逐点覆盖空隙；L² 到 sup 的鸿沟是这条路的本质障碍。
  结论：作为 ∀k 通法**已死**（文献级共识），但其弱化版（对"大多数"速度成立）
  是 Tao 定理的内容，可作为弱界证明的辅助直觉。

### H2. 信息论·KL 亏损流（Explorer-Entropy）

- **降维直觉**：密铺测度与联合测度的刚性信息亏损 ⟹ 空洞存在。对弱界 1/(2k)
  **理论完全够用**（测度对偶已足够），对严格界 1/(k+1) 需要 δ(k) 的锐估计 —
  理论边界卡在锐常数处。
- **真实根因**：本轮是**工具链表达受限**（mathlib Measure API 机械细节），
  骨架已编译通过 — 按 N1 修复策略可闭环弱界。

### H3. 谱图·拉普拉斯切格流（Explorer-Spectral）

- **降维直觉**：λ₂ > 0 ⟺ 轨迹不可截断。美感好但**理论映射有裂缝**：图谱
  截断定捕捉的是图结构，连续环面的区间覆盖不能被图拉普拉斯精确表达 —
  降维存在本质信息损失。结论：辅助性工具，非主攻。

### H4. 实代数·Positivstellensatz 流（Explorer-RealAlgebra）

- **降维直觉**：障碍多项式证书 ⟺ 实闭域无解。对**固定 k 的具体元组**完全
  可行（Farkas/SOS 组合拳）；对 ∀k 通法，证书次数随 k 超多项式爆炸 —
  组合爆炸是理论边界。结论：适合固定 k 的机器证书，不适合通法。

### H5. 物理降维类（退火/自旋玻璃/PSLQ）

- 退火在实战中**已产出全场最佳资产**（最险缝隙 7.96e-9 纪录元组）— 作为
  "反例猎杀引擎"完全验证；作为"证明引擎"不适用。Motzkin-Straus 连续松弛
  （总指挥直觉）未动工 — 落点在 Barajas-Serra 距离图谱系，属高风险探索。

### 突变轨迹图的总结论（零幻觉）

20 个领域对全部通过代数闸口、全部死于 Lean 形式化 — 系统能力边界精确位于
**灵感层与形式化落地层之间**。且闸口"只验真不验强"：多数放行公式为平凡真
（(1−|x|)² ≥ 0 类）。突变中枢的真实价值 = 轨迹图 + 死因基因库，而非个别假说。
