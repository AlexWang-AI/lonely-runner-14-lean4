## 1. 修正后的数学图景（真理论，全部初等可证）

**定理 A（圆引理 = ℝ³ 饱和结构）**：a1 ≠ a2 ∈ ℝ³，|a1−a2| = d < 2。则公共单位邻居集
{x : |x−a1| = |x−a2| = 1} 恰为圆 Γ：中心 m = (a1+a2)/2，半径 ρ = √(1−d²/4)，所在平面 {x : (x−m)·(a2−a1) = 0}。
→ **K_{2,n} 对任意 n 可实现**（圆上任取 n 点）；这是 ℝ³ 局部饱和的唯一形态。

**定理 B（三球交阻碍 = K_{3,3} 刚性阻碍）**：a1,a2,a3 互异，则 {x : |x−a_i| = 1, i=1,2,3} 至多 2 点。
证明链：|b−a1|=|b−a2|=1 ⟹（平行四边形恒等式）|b−m|² = ρ² 且 (b−m)·(a2−a1) = 0；
|b−a3| = 1 ⟹ (b−m)·(m−a3) = 常数（对 b∈Γ 一致）。若 (m−a3) 有平面内分量 → b 落于圆∩线 ≤ 2 点；
若 (m−a3)⊥平面 → 常数条件 |m−a3| = d/2 且 (m−a3)∥(a2−a1) ⟹ a3 ∈ {a1, a2}，与互异矛盾。∎
→ **K_{3,3} ∉ UDG(ℝ³)**；K_{3,3}−e ∈ UDG(ℝ³)（扫描确认）。

**定理 C（CM 符号证书）**：K_{3,3} 模式（9 交叉边=1，6 部内边自由）的 7×7 Cayley-Menger 行列式
**P = 2f(x,y,z)f(u,v,w) − 2x²y²z²u²v²w² = 512A_x²A_u²(1 − R_x² − R_u²)**
（f(a,b,c) = a²b²c² − 16·Area²，海伦形式；SymPy 双恒等式符号验证通过）。
零集 ⟺ R_x² + R_u² = 1（如 R_x = R_u = 1/√2）。此为必要条件，与定理 B 的完全反证互补。

**定理 D（ℝ⁴ Lenz 构造）**：ℝ⁴ 中两正交平面上的圆（半径 r1, r2，r1²+r2²=1）→ 全部交叉距离 = 1 →
K_{m,n} ⊂ UDG(ℝ⁴) 对任意 m,n。综合 B、D：K_{m,n}（m,n≥3）的最小实现维数恰为 4（Maehara：dim(K_{m,n}) = m+n−2）。
